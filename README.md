# Student Tech LK

A static technology resource website for students, with pages covering AI tools, cloud computing and data science.

[Website](https://student.tech.lk.oshadha.live)

## Pages

- Home and About
- AI tools
- Cloud computing
- Data science
- Contact and privacy policy

## Run locally

Clone this repository and open `index.html` in a browser. You can also serve the folder with any local static web server. No build step or package installation is required.

## Structure

HTML pages live at the repository root. Shared styles and scripts are in `style.css` and `script.js`. `CNAME` contains the configured custom domain.

## Contributing

Open an issue for incorrect resources or broken links. For a pull request, explain the change and check the affected pages on desktop and mobile.
